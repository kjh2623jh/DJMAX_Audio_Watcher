# DJMAX Audio Watcher

**DJMAX RESPECT V**가 실행되면 Windows 기본 출력 장치를 **48 kHz**로 변경하고, 게임이 종료되면 기존 출력 형식으로 복구하는 트레이 프로그램입니다.

## 개발 배경

DJMAX RESPECT V에서 ASIO 오디오 출력을 사용할 때, 오디오 장치의 샘플레이트 설정에 따라 게임 외 다른 프로그램의 소리가 출력되지 않는 문제가 발생할 수 있습니다.

이 문제를 해결하기 위해 게임 실행 시 Windows 기본 출력 장치의 샘플레이트를 **48kHz로 자동 변경**하고, 게임 종료 후에는 기존 설정으로 복구하도록 제작했습니다.

이를 통해 게임을 실행할 때마다 Windows 사운드 설정을 수동으로 변경해야 하는 번거로움을 줄일 수 있습니다.

※ 이 문제는 오디오 장치, 드라이버 및 ASIO 설정에 따라 발생 여부가 다를 수 있습니다.

## 사용 방법

1. GitHub Releases에서 통합 배포 ZIP을 내려받습니다.
2. ZIP의 압축을 완전히 해제합니다. 압축된 파일들은 모두 같은 폴더에 두어야 합니다.
3. 폴더 안의 실행 파일을 열고 Windows 관리자 권한 요청을 승인합니다.
4. 실행 방법을 선택합니다.

   - **예:** 로그인할 때 자동 실행
   - **아니요:** 이번에만 실행하고 기존 자동 실행 해제
   - **취소:** 실행하지 않음

5. 작업 표시줄 알림 영역의 아이콘을 우클릭해 상태 확인, 자동 실행 설정, 로그 확인, 종료 기능을 이용합니다.

아이콘이 보이지 않으면 작업 표시줄의 **숨겨진 아이콘 표시(`^`)**를 확인하세요.

## 주요 기능

- DJMAX 실행 시 기본 출력 장치를 48 kHz 스테레오로 자동 변경
- DJMAX 종료 시 실행 전 출력 형식으로 자동 복구
- 이미 필요한 형식이면 불필요한 장치 재설정 생략
- 복구가 확인될 때까지 기존 출력 형식 백업 보관
- 트레이 아이콘에서 상태와 자동 실행 설정 관리

## 사용 전 확인

> Windows 출력 형식을 변경하면 브라우저 등 이미 실행 중인 프로그램의 소리가 끊기거나 무음이 될 수 있습니다. 프로그램과 오디오 장치의 동작은 Windows, 드라이버, 장치에 따라 달라질 수 있습니다.

- 지원 환경은 **Windows 10/11 x64**입니다.
- 게임 실행 중 감시 프로그램을 종료하면 게임 종료를 감지하지 못해 즉시 복구되지 않습니다.
- 감시 프로그램을 다시 실행했을 때 게임이 종료된 상태라면 저장된 설정으로 복구를 다시 시도합니다.

## 문제가 생겼을 때

- 트레이 아이콘을 우클릭한 뒤 **로그 열기**에서 오류 내용을 확인하세요.
- 로그 파일은 `%LOCALAPPDATA%\DJMAXAudioWatcher\watcher.log`에 저장됩니다.
- 출력 형식이 복구되지 않으면 Windows 사운드 설정에서 기본 출력 장치의 형식을 직접 되돌리세요.
- 실행 파일과 `svcl.exe`가 같은 폴더에 있는지 확인하세요.
